关于

      

        DSH 启动器主要功能：
        
    
          
  • 一键启动 / 停止 / 重启 本地大模型（llama.cpp）与 Harness (dsh)；关窗收进托盘，服务后台不停
    • 
          
  • 模型广场：搜索、下载、导入本地模型；按本机硬件推荐合适的量化
    • 
          
  • 版本管理：harness / llama / node / 启动器 的更新、回滚、在已装版本与 GitHub 历史版本间切换
    • 
          
  • 开机自启（后台静默 + 托盘）、更新提示、对话管理（逐条删除 / 一键清空 / 打开文件夹）
    • 
          
  • 环境诊断、GPU 显存监控、控制台实时日志、深浅色主题
    •

        启动器数据全部保存在本目录内；关窗收进托盘、服务后台运行，托盘菜单「退出」才停止全部服务。README 见启动器根目录。
